# A card an agent placed or sized is written back as `move` and a size, without `pin`. Read back with the
# restore author (SPEC.md section 8) it is placed and not pinned, so the board is the same board. Runners
# replay the board they wrote with that author; read back as the user, card k would come back pinned.
agent: topic t T
  -> ok
agent: card k note t Placed by the agent
  -> ok
agent: move k 2 1
  -> ok
agent: size k 4x2
  -> ok
agent: card j note t Placed by the user
  -> ok
user: move j 0 3
  -> ok
agent: card i note t Resized by the user
  -> ok
user: size i 2x2
  -> ok
agent: card h decision t Answered
  -> ok
agent: add h o1 Yes
  -> ok
user: set h chosen o1
  -> ok
agent: card f input t Sent
  -> ok
agent: add f a Name
  -> ok
user: upd f a Name | - | Lee
  -> ok
user: set f sent yes
  -> ok
