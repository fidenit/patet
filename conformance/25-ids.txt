# Ids: 1 to 24 characters, each an ASCII letter or digit, `_`, `-`, or a character above U+007F (see
# 34-id-characters.txt). The same rule for topics, groups, cards, items and named values. The length is counted
# in characters, not bytes.

# Groups, cards, items and named values follow the same rule.
agent: group <24 g> The longest id
  -> ok
agent: group 업무 Hangul
  -> ok

  -> err bad-id
agent: card <24 k> note a The longest id
  -> ok
agent: card 메모 note 여행 Hangul
  -> ok
agent: card k.1 note a A dot
  -> err bad-id
agent: card k1 checklist a Items
  -> ok
agent: add k1 <24 i> todo | The longest id
  -> ok
agent: add k1 <25 i> todo | One too long
  -> err bad-id

  -> ok

  -> ok

  -> ok

  -> err bad-id

  -> err bad-id
agent: let <24 v> the longest name
  -> ok
agent: let 인원 12명
  -> ok

  -> err bad-id
