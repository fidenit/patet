# An id is 1 to 24 characters, each an ASCII letter or digit, `_`, `-`, or any character above U+007F that is
# neither white space nor a control character (SPEC.md section 4). So words of every script are ids, with
# their combining marks, and no Unicode table is needed to tell.

  -> ok

  -> ok
agent: topic مرحبا Arabic
  -> ok
agent: topic 😀 An emoji
  -> ok
agent: topic a·b A middle dot
  -> ok
agent: topic ① A circled digit
  -> ok
agent: topic ¡hola¿ Inverted marks
  -> ok
agent: topic <24 😀> 24 characters
  -> ok
agent: topic <25 😀> 25 characters
  -> err bad-id
# Above U+007F, only the control characters U+0080 to U+009F are refused (white space would end the id).
# The two lines below hold U+0080 and U+009F between a and b.
agent: topic ab A control character
  -> err bad-id
agent: topic ab A control character
  -> err bad-id
# In ASCII, nothing changed: letters, digits, `_` and `-`.
agent: topic a.b A dot
  -> err bad-id
agent: topic a~b A tilde
  -> err bad-id
agent: topic a'b An apostrophe
  -> err bad-id
agent: topic ab U+007F between a and b
  -> err bad-id
