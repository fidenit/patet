# Every card has `fixed` and `watch` (SPEC.md sections 4 and 6), fields of every kind like `by`.
# `fixed` is where a card stays on the screen whatever the user looks at: `x,y`, two whole numbers from 0 to 100,
# checked. `watch` (200) says how the card is kept fresh, in the host's own words. On a record neither counts toward
# the 12 fields.
agent: topic t T
  -> ok
agent: card k status t Disk
  -> ok
agent: set k fixed 72,6
  -> ok
agent: set k watch on gpu, every 10 min: df -h / | tail -1
  -> ok
