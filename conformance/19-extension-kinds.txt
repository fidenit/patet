# Extension kinds: `x-` and an id. Every renderer accepts one, checks it as a record (any field name that is an id,
# rows of up to 6 cells) and writes it back under its own name. Any other unknown name is rejected.
agent: topic t Sprint
  -> ok
agent: card k1 x-kanban t Sprint 12
  -> ok
agent: set k1 lane Doing
  -> ok
agent: set k1 text Free text, as in a record.
  -> ok
agent: set k1 cols Task | Owner
  -> ok
agent: add k1 a Write the spec | me
  -> ok
agent: add k1 b one cell
  -> ok
agent: add k1 c a | b | c | d | e | f
  -> ok
agent: upd k1 a Write the spec | you
  -> ok
agent: del k1 b
  -> ok
agent: set k1 a!b x
  -> err unknown-field
agent: add k1 d a | b | c | d | e | f | g
  -> err cell-count
agent: upd k1 z not there
  -> err no-such-item
agent: set k1 title Sprint 13
  -> ok
